Because train and test come from different genomes, I split my validation by genome so I was always testing on unseen ones. My first co-occurrence model scored below the baseline, so I dug in and found the masked token sits in some sibling contig 94% of the time — recall wasn't the problem, ranking was. The fix that worked was collaborative filtering: I rank each candidate by how strongly it shows up in the sibling contigs most similar to the target one, weighting rarer shared k-mers more and discounting genome-ubiquitous ones. A from-scratch transformer overfit the genomes badly, so I kept the model count-based and transductive.
